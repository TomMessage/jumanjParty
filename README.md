# Welcome to the Board

A Godot 4.7 party game: a cursed board on a candlelit table. This branch holds the foundations and the visual slice (Phases 1 and 2).

```bash
tools/validate.sh
```

Requires Godot 4.7.x and `gdtoolkit` 4.5 (`gdformat`, `gdlint`) on `PATH`. Play the menu with `godot --path .`. Keys 1–4 look at the table, the board, the game master, and the window.
